# 折腾 Zheteng · 开屏广告的艺术

> 大展身手，小折一下。把选择权，交还给你的铰链。

一个 Android 折叠屏讽刺小品：打开 App，先看 120 秒开屏广告。没有“跳过”按钮，只有一个需要拿捏分寸的折叠动作。

## 玩法

1. 先把设备展开至 **165° 或以上**。
2. 轻折至 **100°–120°**（含边界）。
3. 再展开至 **165° 或以上**，成功进入首页。

一次动作的**最小角度**决定结果。折到 70° 再经过 105°，仍然算折过头。只折到 140° 就展开，则算折得不够。另有故意不在开屏主说明中披露的 **3 秒动作时限**：折叠低于 165° 时开始计时，超时未完成时无需等待展开或下一条传感器事件，就会自动触发购物模拟跳转。失败提示一律使用讽刺性的“恭喜！”措辞。失败会随机显示**X宝、X东、X夕夕**之一的模拟开屏，仿佛广告擅自打开了另一个 App。点击“返回”可以继续尝试。120 秒结束后自动进入首页。

购物应用使用虚构名称，仅用于讽刺表达，与任何品牌无关联。所有购物“跳转”都在本 App 内完成，不会启动或安装其它 App。

## 名称与视觉

**折腾**：既是折叠，也是本来不必经历的一番折腾。

珊瑚红、米白纸色、深墨绿；标志把折叠屏与跳过箭头合成一个图形。Android 自适应图标、单色主题图标和可编辑的 [SVG 标志](branding/zheteng-logo.svg) 均已包含。插图以 Compose Canvas 绘制，无远程图片依赖。

## 设备与演示

- Android 11 / API 30 及以上。
- 在提供 `Sensor.TYPE_HINGE_ANGLE` 的折叠设备上直接读取铰链角度；0° 表示合拢，180° 表示展开。不需要传感器权限。
- 无可用传感器时，自动显示明确标注的“模拟铰链”滑杆。先向左拖到目标区间，再拖回最右侧即可演示成功；目标区间之外往返即可演示失败。
- 设备报告有传感器但没有读数时，可在右上角“?”中选择演示模式。
- 排版仅按窗口宽度调整：大屏双栏、小屏单栏滚动，不根据铰链姿态切换布局。铰链角度仅用于游戏判定。
- 深色模式跟随系统，涵盖背景、卡片、文字、角度仪与系统栏。
- 倒计时基于 `SystemClock.elapsedRealtime()` 累计广告界面停留时间；离开界面或进入模拟购物页时暂停，旋转或 Activity 重建不重置。3 秒动作时限同样随界面暂停。首页统计显示打开主应用前的前台停留耗时，进入后固定不变。
- 每个新任务启动一个 120 秒会话；返回同一任务会继续原会话。系统返回 / 主屏幕手势始终可用。
- 不联网，无广告 SDK、账号、分析、购物深链或权限申请。

## 构建

在 Android Studio 中打开本目录，使用 JDK 25（项目 Daemon JVM 配置）与 Android SDK Platform 37。

```sh
./gradlew :app:assembleDebug
./gradlew :app:lintDebug
```

- Kotlin、Jetpack Compose、Material 3。
- AGP 9.4.1 / Gradle 9.6.0 / Kotlin Compose 编译器 2.3.21。
- `compileSdk` / `targetSdk`: 37；`minSdk`: 30。
- 按要求未保留单元测试或 Android 测试套件；以构建、lint 和模拟器目视检查验证。
- 调试包输出：`app/build/outputs/apk/debug/app-debug.apk`。

## 实机限制

并非每台折叠设备都向第三方提供连续铰链角度；不同机型精度也不同。本版本提供真实传感器实现和演示功能。

官方 API 参考：[铰链角度传感器](https://developer.android.com/reference/android/hardware/Sensor#TYPE_HINGE_ANGLE)、[折叠感知与铰链布局](https://developer.android.com/develop/adaptive-apps/guides/foldables/make-your-app-fold-aware)。
